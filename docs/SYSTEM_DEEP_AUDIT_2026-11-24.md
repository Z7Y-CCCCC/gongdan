## 发布与剩余边界

- 新移动统计需配套升级后端。BOM 的三个 BigDecimal 响应字段改为字符串，管理端和外部调用方须按新契约升级；旧数字请求仍兼容。本轮未新增数据库迁移，前轮 V23–V25 及其发布要求仍见迁移记录。
- 本轮全套没有启用本机 MySQL 迁移测试；前轮 MySQL 8.4 隔离验收见 `MYSQL_MIGRATION_COMPATIBILITY.md`。新增聚合的数据库功能与查询次数验证使用 H2，正式发布仍需业务备份隔离演练和真实部署基线回归。
- 移动报工历史仍有 5,000 条全页助手上限，并提示截断；通知历史补发仍每类 50 条。其他旧式有上限列表不能据此当成已逐页验收。
- 微信真机、真实短信、真实插件持久化、生产反向代理和生产容量压测未验收。API 映射冒烟不代替每个业务动作的完整测试；本轮确认缺陷已修复，不宣称所有潜在 bug 清零。

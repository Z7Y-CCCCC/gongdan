# 插件平台验收报告

验收对象为核心插件中心、插件运行容器、核心代理，以及新增的
`equipment-inspection 1.0.0` 设备点检测试插件。

## 验收结论

当前实现达到“受控的工厂级插件平台底座”预期：超级管理员可以登记目录和版本，管理员可以按工厂安装、
配置、启用、检查、停用、回滚和卸载；健康异常时菜单和接口自动隔离；插件页面不持有
核心登录令牌；核心到插件的请求已使用时间窗、请求体摘要和 HMAC 网关签名。它尚未达到
“从互联网下载任意插件并自动安全运行”的商业插件商店标准，制品签名、自动部署、独立持久化
和供应链扫描仍需后续建设。

## 已知限制

- 测试插件使用内存数据，只验证平台协议，不能保存生产数据。
- `checksum` 目前只登记元数据，尚未对实际下载制品执行校验和签名验证。
- 插件部署、容器资源限制、数据库迁移和跨版本兼容仍由运维流程负责。
- 质量管理旧样板和设备点检样板都已接入网关签名校验，但仍使用内存数据，只适合验收演示。
- 在供应链能力完成前，目录和版本登记权只应授予超级管理员，后端与前端白名单必须
  使用固定内网主机和受控 HTTPS 来源。

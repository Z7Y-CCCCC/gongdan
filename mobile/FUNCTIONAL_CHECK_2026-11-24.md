## 验证

- `npm test`：**130/130**，无失败或跳过。真实 TS/Vue setup 编译、API 和生命周期适配器测试；包括新增 15 项行为回归及旧依赖安全回归。
- `npm run build`：类型检查与 H5 生产构建成功；`npm run build:mp-weixin`：生产构建成功。微信 JS 产物未包含 H5 QR 解码模块。
- QR 解码用真实生成的像素样本，不是解码函数桩。`qrcode-reader@1.0.4` 为固定运行依赖（Apache-2.0），`qrcode-terminal@0.12.0` 仅作固定开发测试生成器；现有包离线更新锁文件，未新增网络安装。
- 图片限制：10 MiB 文件、16M 原图像素、最多 1,048,576 解码像素；失败可重选，不上传扫码照片。
- 390×844 隔离生产 H5：扫码识别、报工照片上传→提交→鉴权预览、报工分页 20→40/失败恢复、核心任务/搜索/报工/待审/驳回/现场事件/返回看板、减少动态效果及退出均做真实点击，无 force-click。
- 新干净浏览器的画廊/核心/退出流程无应用脚本错误；一次 HTTP 503 是明确注入的分页故障。旧失败截图/日志保留以记录已修缺陷，不当作最终通过证据。

日志：`test/mobile-functional-all.log`、`test/mobile-functional-build-h5.log`、`test/mobile-functional-build-weixin.log`。浏览器证据在项目 `output/playwright/mobile-functional/`，核心复现脚本为 `test/ui-browser-scenario.mjs`；它需要隔离 `browser-fixture.mjs`，不可对真实数据运行。

## 边界

- `WorkOrderResponse.unitName` 由后端同步补齐并按真实产品单位映射；缺失为 null，端上不猜测“个”。跨产品汇总不附统一单位。
- 第 251 页回归证明客户端可请求第 5,001 条位置，并使用现有分页契约；未声称插入 6,000 条真实数据库记录或做生产压测。
- 微信真机、真实 AppID/HTTPS API/授权平台凭据，以及设备摄像头权限/拍照本身未验收；拍照入口与本地图片解码不能代替真实硬件测试。
- 本轮未提交、推送或部署，由主代理汇总后更新 GitHub。
